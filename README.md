🏰 Лабиринт Сокровищ
Текстовая консольная игра-приключение в жанре квеста. Исследуйте древний лабиринт, решайте загадки, собирайте предметы и найдите легендарные сокровища.

🚀 Быстрый старт
Требования
Python 3.8 или выше

Poetry (менеджер зависимостей)

Установка
bash
Установите зависимости
poetry install

Или используйте make
make install
Запуск игры
bash
 Запуск через poetry
poetry run python labyrinth_game/main.py

Или через make
make project

🗺️ Игровой мир
Комнаты:
Entrance (Вход) - Начальная точка, здесь находится факел

Hall (Зал) - Центральная комната с загадкой на пьедестале

Trap Room (Комната ловушек) - Опасная комната с плиточным полом

Library (Библиотека) - Комната с древними книгами

Treasure Room (Комната сокровищ) - Финальная комната с сундуком

Предметы:
🔥 Факел - Защищает от ловушек, освещает путь

🗝️ Ключи (Золотой и Ржавый) - Открывают дверь в сокровищницу

📜 Древняя книга - Даёт подсказки

💰 Золотая монета - Случайная находка

🎯 Как победить
Возьмите факел в Entrance (take факел)

Решите загадку в Hall (solve → ответ 10)

Получите ключ (золотой или ржавый)

Пройти в Treasure Room (north из Hall)

Откройте сундук (use ключ или solve)

Альтернативный путь:
Решите загадку в Trap Room (шаг шаг шаг)

Получите ржавый ключ

Откройте сундук в Treasure Room

⚠️ Особенности игры
Случайные события (10% шанс при перемещении):
Находка монетки 💰 - появляется в комнате

Шорох в темноте 👹 - меч защищает от монстра

Активация ловушки 💥 - только в Trap Room без факела

Озарение 💡 - полезная подсказка

Ловушки:
В Trap Room без факела есть риск активации ловушки

Ловушка может забрать случайный предмет

Без предметов есть шанс проигрыша
